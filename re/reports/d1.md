## `// shortcut:` guesses
1. **MovieListView.load**: I parse with `try Network().parse(html:)` on a throwaway instance.
   - Why: the binary inlined a Network listing parser that returns a fresh array (checkPremium, then the private card helpers of Network.swift, then `list.append(contentsOf:)`). That parser is not in Network's API.
   - The result and the premium side effect are identical. Replace it once Network gains the method (contract request 1).
2. **CollectionsCardViewComponent(+Ipad)**: the `.scaleEffect` factor is loaded from a stack slot I did not recover (0x10008c0d8), so I used 1.
3. Approximate without a comment (layout only):
   - BackButton/ShareButton `aspectRatio(contentMode: .fit)`;
   - quick-search line limits 2/3 and card line limits;
   - VStack spacings;
   - blur radius 15 of the poster highlight.

## Contract requests
1. Network (a2): add `func parseList(html: String) throws -> [MovieSimple]`. It should do checkPremium and the same card parsing as `parse(html:)`, but into a fresh local array, without touching `movies`. The call site is MovieListView.load (binary 0x10008fecc).
2. Wipe (d2): my posters call `.transition(.wipe(angle: .degrees(45), blurRadius: 10))` and rely on d2's `wipe()` wiping back along angle + 180°.
   - The binary's `wipe()` (0x100042754) is a single symmetric `.modifier(active:identity:)`. Its call sites were `.asymmetric(insertion: .wipe(45°), removal: .wipe(225°))`.
   - If d2 makes `wipe()` symmetric again, the four poster call sites (and d2's PersonCardComponent / PersonPosterView) must switch to the asymmetric form.

## Notes for other areas
- Request builders are static and tested: `SearchView.quickSearchRequest`, `SearchResultsView.searchRequest` and `MovieListView.pageRequest`. They build the same request as the binary's `AF.request(url, parameters:, encoder: URLEncodedFormParameterEncoder.default, headers:)` through a2's `siteRequest`. If building fails (an unusable mirror string), the request is skipped instead of failing inside Alamofire.
- `SharedFilmId.id` must hold the full page URL (`https://<mirror>/…html`) before a ShareButton appears, or the `URL(string:)!` traps, as in the binary.
